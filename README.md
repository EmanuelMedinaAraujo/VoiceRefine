# VoiceRefine

Collects my own dictation audio together with its transcript, with no extra effort while dictating, so the pairs can later fine-tune a speech-to-text model for personal use.

It sits beside [Voxtype](https://voxtype.io) on [Omarchy](https://omarchy.org): every dictation is recorded, the transcript and the model that produced it are logged, and corrections made afterwards are picked up as the better label.

Status: design phase. Nothing is implemented yet.

Recordings and transcripts stay on the local machine and are never committed here.
